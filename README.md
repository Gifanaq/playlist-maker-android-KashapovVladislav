# playlist-maker-android-KashapovVladislav
Учебный проект по созданию мобильного приложения

Инструкция по сборке:
--Склонируйте репозиторий или загрузите исходный код;
--Откройте проект в Android Studio;
--Дождитесь завершения индексации и загрузки зависимостей (Gradle Sync);
--Подключите Android-устройство с API 28+ или запустите эмулятор;
--Запустите приложение: Run → Run 'app'.

Язык и платформа:
--Язык: Kotlin;
--Минимальная версия SDK: Android 9.0 (API 28);
--Целевая версия SDK: Android 11+.
