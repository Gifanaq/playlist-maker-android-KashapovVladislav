# playlist-maker-android-KashapovVladislav
Учебный проект по созданию мобильного приложения Playlist Maker

Инструкция по сборке:
-- Склонируйте репозиторий;
-- Откройте проект в Android Studio (рекомендуется версия Ladybug или новее);
-- Дождитесь завершения Gradle Sync;
-- Подключите устройство с API 28+ или запустите эмулятор;
-- Запустите приложение: Run → Run 'app'.

Изменения по спринтам:

-- Спринт 3-6:
1) Создана базовая структура приложения (Поиск, Настройки, Главная);
2) Реализован поиск треков через iTunes API с использованием Retrofit;
3) Внедрена ViewModel и управление состояниями экрана поиска.

-- Спринт 7-9:
1) Добавлены современные компоненты UI: FloatingActionButton и BottomSheet;
2) Реализовано создание плейлистов и экран деталей трека;
3) Интегрирована библиотека Coil для асинхронной загрузки обложек.

-- Спринт 10:
1) Осуществлен переход на постоянное хранение данных через базу данных **Room**;
2) Реализована сложная связь "многие ко многим" (трек может быть в нескольких плейлистах);
3) История поиска мигрирована на **Jetpack DataStore**.

-- Спринт 12 (Финал):
1) Доработан экран **Избранное**: удаление по долгому нажатию и навигация в плеер;
2) Реализован выбор обложки плейлиста из галереи устройства;
3) Добавлена функция удаления трека из конкретного плейлиста;

Технологический стек:
-- Язык: Kotlin;
-- UI: Jetpack Compose;
-- Хранение: Room Database, DataStore;
-- Сеть: Retrofit, GSON;
-- Загрузка изображений: Coil;
-- Минимальная версия SDK: Android 9.0 (API 28);
-- Целевая версия SDK: Android 15.0 (API 35).
